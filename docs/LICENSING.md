# Licensing policy

Original PhraseLayer source is Apache-2.0. Track third-party source/library licenses, model-weight licenses, and dataset licenses separately. A runtime/library license does not automatically cover the weights loaded by it.

Model binaries are not committed until the exact revision is pinned, redistribution is allowed for the intended release, notices are documented, and runtime compatibility is verified. Meta sample code copied into PhraseLayer must retain its applicable upstream file-level license/notice.
